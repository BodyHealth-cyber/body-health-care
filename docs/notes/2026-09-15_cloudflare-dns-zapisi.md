# DNS для почты — 4 записи в Cloudflare

Дашборд Cloudflare у меня не прогрузился (бесконечный спиннер на
`/dns/records`, три попытки). У вас в обычном окне он, скорее всего, откроется
нормально. Записи ниже готовы — скопировать и вставить.

**Ничего не удалять.** Существующие `A` и `CNAME` (сайт, `app.`, `www`) не
трогаем — только добавляем четыре новых.

Открыть: **body-health.care → DNS → Records → Add record**

---

### 1. Подтверждение домена для Google

| Поле | Значение |
|---|---|
| Type | `TXT` |
| Name | `@` |
| Content | `google-site-verification=HNUzRj376U-k1sVexg1823neB3WyGUbAmvKKP0ECyqc` |
| TTL | Auto |

### 2. Приём почты — MX

| Поле | Значение |
|---|---|
| Type | `MX` |
| Name | `@` |
| Mail server | `smtp.google.com` |
| Priority | `1` |
| TTL | Auto |

Одна запись, не пять. Старый набор `ASPMX.L.GOOGLE.COM` и компания Google больше
не требует — `smtp.google.com` с приоритетом 1 это актуальная замена всем пяти.

### 3. SPF — кто имеет право слать от нашего домена

| Поле | Значение |
|---|---|
| Type | `TXT` |
| Name | `@` |
| Content | `v=spf1 include:_spf.google.com ~all` |
| TTL | Auto |

### 4. DMARC — политика и отчёты

| Поле | Значение |
|---|---|
| Type | `TXT` |
| Name | `_dmarc` |
| Content | `v=DMARC1; p=none; rua=mailto:security@body-health.care` |
| TTL | Auto |

`p=none` — режим наблюдения: письма никуда не денутся, но мы будем получать
отчёты, кто шлёт от нашего имени. Через пару недель, когда убедимся, что всё
легитимное подписывается, ужесточим до `quarantine`.

---

## Почему это не формальность

Без SPF и DKIM письма с `@body-health.care` уходят в спам — а первое письмо
пациенту, попавшее в спам, это потерянный пациент. Без DMARC домен медицинской
клиники может подделать кто угодно: разослать от имени `info@body-health.care`
что угодно кому угодно. Для клиники это не теоретический риск.

## После того как добавите

1. Вернуться во вкладку **Domain setup** (Google Workspace).
2. Поставить галочку **«Come back here and confirm once you have updated the
   code on your domain host»**.
3. Нажать **Confirm**.

Подтверждение обычно проходит за минуту-две — Cloudflare отдаёт записи почти
мгновенно.

## Что я делаю сразу после подтверждения

- **DKIM** — генерирую ключ в админке и добавляю пятую запись
  (`google._domainkey`). Это делается только после подтверждения домена, раньше
  Google ключ не выдаёт.
- **7 алиасов** на `info@body-health.care`: `sales@`, `office@`, `director@`,
  `support@`, `billing@`, `security@`.
- **Ярлыки и фильтры** — по одному на адрес, плюс Send-as для каждого.
- **Перенос старой почты** — весь архив и контакты из
  `bodyhealthmediclinic@gmail.com`, плюс постоянная пересылка оттуда.
- **Тестовое письмо** — и только после того как оно дойдёт, меняю 51 адрес на
  сайте.
