# Архив редакций правовых документов

Физические снимки опубликованных редакций. Юрист требует возможности доказать,
какая редакция действовала на дату акцепта оферты (п. 3.2 и Шаг 4 ответа от 16.09.2026).

Публичная страница архива: `/legal-archive.html` — она перечисляет редакции и даты,
а сами снимки хранятся здесь и выдаются по запросу на info@body-health.care.

## Как пополнять

При каждом изменении правовых текстов — до пуша:

```bash
bash build.sh
D=$(date +%Y-%m-%d) && mkdir -p docs/legal-archive/$D
for f in terms-and-conditions/uk.html terms-and-conditions/en.html terms-and-conditions/ru.html \
         refund-policy.html en/refund-policy.html ru/refund-policy.html \
         privacy.html en/privacy.html ru/privacy.html; do
  cp "dist/$f" "docs/legal-archive/$D/$(echo $f | tr '/' '_')"
done
```

Затем обновить раздел «Історія редакцій» в `resources/views/legal-archive.html`.
