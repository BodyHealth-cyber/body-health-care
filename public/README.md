# BodyHealth - Веб-сайт системы медицинского сопровождения

Современный веб-сайт для системы персонализированного медицинского сопровождения BodyHealth, выполненный в минималистичном стиле WHO.int с акцентом на доказательную медицину и профессионализм.

## 📋 Описание проекта

BodyHealth - это международная платформа цифрового здравоохранения, основанная в 2018 году, работающая в Украине, Германии, с регистрацией IP в Сингапуре. Компания предоставляет персонализированную систему медицинского сопровождения с командой из 70+ сертифицированных специалистов из 14 медицинских областей.

### Ключевые показатели:
- **92%** удовлетворённости пациентов
- **70+** сертифицированных специалистов  
- **68%** пациентов с хроническими заболеваниями показали измеримое улучшение
- **43%** снижение выраженности симптомов
- **38%** уменьшение потребности в коррекции медикаментов

## 🎯 Цели и аудитория

### Основные цели:
- Презентация системы BodyHealth для разных аудиторий (B2C, B2B2C)
- Обеспечение записи на консультации для частных лиц
- Привлечение корпоративных клиентов и партнёров
- Продвижение на рынке США с партнёрской моделью

### Целевые аудитории:
1. **B2C**: Частные пользователи, заботящиеся о здоровье
2. **B2B2C**: Работодатели и страховые компании  
3. **Партнёры**: Медицинские клиники и врачи

## 🎨 Дизайн-система

Сайт выполнен в стиле WHO.int с соблюдением принципов минимализма:

- **Основной**: #ffffff (белый фон)

### Компоненты:
- Липкий хедер с выпадающей навигацией
- Адаптивная сетка (12 колонок, max-width 1280px)
- Карточки услуг с hover-эффектами

## 🚀 Развертывание

### Требования:
- Любой веб-сервер (Apache, Nginx, или статический хостинг)
- Поддержка HTML5, CSS3, ES6+
- HTTPS сертификат (рекомендуется)

### Рекомендуемые платформы:
- **Vercel** (оптимально для статических сайтов)
- **Netlify** (с формами и функциями)
- **GitHub Pages** (бесплатный вариант)
- **AWS S3 + CloudFront** (корпоративный уровень)

### Шаги развертывания:
1. Загрузить файлы на сервер
2. Настроить HTTPS сертификат  
3. Настроить редиректы (index.html как главная)
4. Подключить аналитику (Google Analytics, Yandex.Metrika)
5. Настроить формы (интеграция с backend или сервисом форм)
